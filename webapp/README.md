# Chatbot (RAG) — Webapp

Frontend en **React + Vite + TypeScript**: chat, subida de archivos y consultas al backend.

## Arranque

```bash
cd webapp
npm install
npm run dev
```

Por defecto la UI llama a `http://localhost:3000` en desarrollo (ver `src/config/constants.ts`). En producción usa la URL de Render definida ahí.

## Scripts

- `npm run dev` — servidor de desarrollo (Vite).
- `npm run build` — compilación para producción.
